# Tempest include list for Nova compute API tests.
#
# One regex pattern per line. Lines starting with # are comments.
# Blank lines are ignored. Patterns are matched against test IDs.
#
# The single pattern takes the whole compute tree. It lands in the core phase of
# the runner's scope split, which sorts every line on ^tempest\. against
# ^<x>_tempest_plugin\. (hack/ci-run-tempest.sh), so the plugin phase stays
# empty. The runner allows that and skips the empty phase.
#
# The tests the fake compute cannot serve are switched off through
# [compute-feature-enabled] in tempest.conf or listed in exclude-tests.txt, so a
# leg that later runs a real driver needs a flag flipped rather than this
# pattern rewritten.
