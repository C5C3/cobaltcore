# Tempest include list for Neutron network API tests.
#
# One regex pattern per line. Lines starting with # are comments.
# Blank lines are ignored. Patterns are matched against test IDs.
# Only network tests are included: no other service is deployed on this leg.
#
# The leg has a flat external network (05-external-network-job.yaml), so the
# router, floating-IP and external-network suites run next to the CRUD of
# networks, subnets, ports, security groups and subnet pools. All of them stay
# at the API: Neutron writes the matching logical switch ports, logical router
# ports and NAT rows into the OVN Northbound database. The reachability
# (scenario) suites stay out: there is no gateway chassis with an uplink and no
# guest.
