# stestr exclude-list for Nova 2026.1
#
# One regex pattern per line. Lines starting with # are comments.
# Blank lines are ignored. Patterns are matched against test IDs.
#
# No pattern: the first run of the nova 33.0.0 suite in the venv-builder
# container, with OS_NOVA_DISABLE_EVENTLET_PATCHING=False the way nova's own
# tox py3 env runs it (hack/ci-run-unit-tests.sh sets it), counted 16803
# tests and passed with no environment-dependent failure. The 63 skips and
# the 2 expected failures are upstream's own.
#
# Without that variable the run ends in stestr discovery: nova/cmd/
# scheduler.py selects the threading backend at import while
# nova/tests/unit/__init__.py has already selected eventlet, and oslo.service
# raises BackendAlreadySelected. No pattern in this file can reach that
# failure, because stestr imports every test module before it applies the
# exclude list. The runner sets the variable instead.
#
# Record a future environment failure here as one escaped regex with a
# comment above it stating the reason.
